Galaxy Syndrome Uploader

Galaxy Syndrome Uploader is a private tool run by Amastrata Media. It uploads short videos that Amastrata Media produces to Amastrata Media's own YouTube channels using the YouTube Data API, and reads view statistics for those videos using the YouTube Analytics API.

The tool is used only by Amastrata Media for its own channels. It is not offered to the public and does not access anyone else's account.
