Privacy Policy

Effective: 29 October 2026

This policy covers Galaxy Syndrome Uploader, a private tool operated by Amastrata Media (home page).

What data the app accesses

When the channel owner signs in with Google, the app receives an OAuth access token and refresh token, basic YouTube channel information (channel ID and name), and view statistics for videos on that channel.

How the data is used

The data is used only to upload videos produced by Amastrata Media to its own YouTube channels and to read performance statistics for those videos. It is not used for advertising, profiling, or any other purpose.

Storage and sharing

Tokens and statistics are stored only on Amastrata Media's own computer. Google user data is never sold, shared with, or transferred to third parties.

Google API Services

Galaxy Syndrome Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Stored tokens and statistics are deleted on request.
